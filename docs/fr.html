Foire aux questions

Comment afficher des diagrammes Mermaid dans Google Gemini ?

Normalement, Gemini affiche le code Markdown brut pour les graphiques. Gemini Polish détecte automatiquement la syntaxe Mermaid et fournit un rendu de diagramme haute définition en vue fractionnée directement dans votre fenêtre de chat.

Améliore-t-il le formatage Markdown de Gemini ?

Oui ! En plus d'être un puissant outil de création de diagrammes d'IA, cette extension de navigateur agit comme un moteur de thème complet. Elle améliore la typographie par défaut de Google Gemini, la coloration syntaxique des blocs de code et la mise en page globale pour une meilleure expérience utilisateur.

Est-ce utile pour les diagrammes d'architecture logicielle complexes ?

Absolument. Nos fonctionnalités d'interaction professionnelles incluent le zoom au pavé tactile, le panoramique par glissement et le mode plein écran, ce qui en fait le visualiseur idéal pour les architectures logicielles complexes, les diagrammes de séquence et les organigrammes générés par l'IA.

Corrige-t-il les polices CJK (chinois, japonais, coréen) ?

Oui ! Un problème majeur avec l'interface native de Gemini est le mauvais rendu des polices pour les langues asiatiques. Nous imposons des polices de secours strictes (PingFang, Hiragino, Malgun Gothic) pour nous assurer que les caractères chinois, japonais et coréens s'affichent parfaitement sur tous les systèmes d'exploitation.
